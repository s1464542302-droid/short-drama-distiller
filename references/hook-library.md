# 钩子类型库与填空公式

钩子只负责勾起好奇，不负责讲完故事。使用前 3 秒必须出现冲突、危机或反转中的一个；禁止把谜底在前 3 秒说完。

## 四大类钩子

### 1. 羞辱打脸型

投产最高的类型，适合赘婿、豪门、重生、婆媳逆袭题材。

- **公式**：主角当下遭受具体羞辱 + 对方放出狠话 + 埋下反转伏笔
- **关键**：羞辱要具体，写动作和台词，不写"别人看不起她"这类空泛表述
- **潜台词钩子**：她接下来会怎么反击？
- **填空示例**：[具体羞辱动作] + "[对方的狠话]" + [一个暗示身份/底牌的细节]

### 2. 危机绝境型

适合悬疑、亲情、重生题材，情绪沉重但粉丝粘性强。

- **公式**：致命危机降临 + 倒计时或紧迫后果 + 主角无路可退
- **关键**：必须给出明确的时间压力和后果，不能只是"遇到了麻烦"
- **潜台词钩子**：能不能救回来？谁会来救？
- **填空示例**：[危机信号] + "只剩 [时间]，否则 [后果]" + [主角无路可退的状态]

### 3. 反差预知型

重生、穿越、先知类标配，靠台词驱动，新手友好。

- **公式**：主角拥有别人不知道的未来信息 + 说出一句颠覆当下的话
- **关键**：预言必须具体且可验证，让观众想确认会不会成真
- **潜台词钩子**：她怎么知道？预言会不会成真？
- **填空示例**：[众人正在做的错事] + 主角冷冷开口 "[颠覆性预言]"

### 4. 选择两难型

适合甜宠、轻悬疑、家庭题材。

- **公式**：摆在主角面前两个选项 + 两个选项都有巨大代价
- **关键**：代价必须要具体且都难以承受，不能一边明显更好
- **潜台词钩子**：主角会怎么选？
- **填空示例**："要么 [代价一]，要么 [代价二]"

## 常见变体

- **痛点直击**：直接点出用户日常困扰，"你是不是也遇到过……"
- **悬念冲突**：疑问句或反常识结论
- **强吸引式**：极端词汇制造冲击，"这是我见过最狠的……"
- **反常理式**：越反常理越吸睛，"买得起 1000 万别墅，吃不起 30 块快餐"
- **提问反问**：引发好奇，寻求答案

## 三条硬性规则

1. **画面与台词同步**：钩子必须落在台词 + 画面，不能只靠字幕。羞辱台词配压迫感镜头，危机台词配紧张氛围。
2. **不要剧透结局**：钩子只抛疑问，不交代结果。错误示范："当年抛弃我的妈妈今天来求我原谅，我最后原谅她了"——结局已说，直接划走。
3. **钩子后 30 秒内兑现第一层冲突**：抛出后不能长时间冷场铺垫。顺序：钩子(0–3s) → 强化冲突(3–30s) → 第一次小反转(60s 内)。

## 审核红线

钩子追求强冲突，但不能碰：人身恶意攻击、侮辱残障群体、涉黄暗示、极端血腥、威胁生命的过激台词。触发风控后钩子再好也没有流量。
