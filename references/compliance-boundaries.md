# 合规边界（2026 年环境）

## 监管与平台背景

- 2026 年"剑网行动"把无授权剧情解说列为整治对象，影视二创、AI 短剧是版权合规重点
- 腾讯与抖音二创版权合作到期后，平台对无授权影视剪辑限流、下架
- 平台查重机制升级：镜像翻转、变速、加滤镜、掐头去尾、简单加字幕的搬运式二创会被判定为低质混剪
- 司法口径：单纯搬运片段、无独立观点评论、无原创二次表达，即便不盈利也构成信息网络传播权侵权

## 四类绝对红线

1. **版权替代式创作**：做"X 分钟看完一部剧"，完整梳理剧情、剧透结局、还原核心高潮，让观众看完不需要看原作。这是侵权，不是合理使用。
2. **低成本无意义加工**：镜像、调速、滤镜、掐头去尾、简单加字幕，无内容重构和观点输出。
3. **素材引用超标**：单段原素材超过 3–5 秒、整体原素材占比超过 30%、照搬原片镜头顺序。
4. **音频照搬**：不替换原片人声、直接用未授权热门 BGM、照搬原视频音效。

## 合理使用的边界

《著作权法》第 24 条允许为介绍、评论某一作品而适当引用，条件是：指明作者姓名和作品名称、不影响作品正常使用、不损害权利人合法权益。

**能站住合理使用的**：少量片段引用 + 目的是评论分析 + 不引流带货 + 不剧透结局 + 引用不作为视频主要看点。

**站不住的**：商业变现（广告、带货、付费、流量分成）场景下的剧情复述；用原作核心剧情和人物设定作为主要卖点；连续多集解说替代原剧。

## 合规解说四条做法

1. **拿授权**：短剧推广/分销是主流变现方式，很多平台和片方给推广者开放官方素材授权，优先走这条路。
2. **做评论型解说**：原剧画面只作佐证，主体是观点增量——人物动机分析、叙事手法点评、现实议题延伸、逻辑漏洞讨论，观点内容至少占 50%。
3. **真人原创配音 + 全替换音频**：删除原声和原 BGM，自己口播，BGM 用平台无版权素材库。
4. **画面打碎重组**：多源素材混剪、裁剪画幅、缩放构图、打乱顺序、加原创贴纸水印，原素材不占主体。

## 交付前自检清单

- [ ] 脚本是否包含至少 50% 的原剧没有的观点内容？
- [ ] 是否未明说结局、未还原完整故事线？
- [ ] 原剧画面引用是否为短片段、不连贯、不占主体？
- [ ] 是否标注了剧名与权利人？
- [ ] 配音是否为原创口播，原声原 BGM 是否已全部删除？
- [ ] 是否无第三方水印、二维码、外部导流内容？
- [ ] 是否运行 `scripts/compliance_check.py` 且无高风险项？
- [ ] 是否保留了脚本原稿、工程文件、素材来源记录作为申诉证据？

## 误判申诉要点

被误判违规/侵权时，申诉重点证明：原创改动幅度大、有独立创作过程、有全新信息增量、属于合理引用、未替代原作品。提前留存剪辑工程文件、原始素材、配音源文件、文案原稿。
