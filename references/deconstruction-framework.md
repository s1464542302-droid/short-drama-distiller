# 爆款短剧解说拆解框架

## 拆解的四个层次

拆解的目标是把一条爆款从"成品"还原成"配方"。按以下四层从上到下拆，每层只记录结构，不记录内容。

### 第一层：钩子（0–3 秒）

记录三件事：

- **钩子类型**：从 `hook-library.md` 的四类中归类（羞辱打脸 / 危机绝境 / 反差预知 / 选择两难），可复合
- **触发的情绪**：愤怒、好奇、委屈、紧张、共鸣中的哪一种
- **信息差类型**：观众不知道而主角知道、观众知道而角色不知道、所有人都不知道的悬念

只记录"它用了哪种钩子"，不复制钩子原句。把原句改写成填空公式，例如"主角当下遭受具体羞辱 + 对方放狠话 + 埋反转伏笔"。

### 第二层：情绪曲线（3 秒到结尾）

标准曲线五节点：

| 节点 | 时间区间 | 观众情绪 | 可学的手法 |
|------|----------|----------|------------|
| 痛点代入 | 3–10s | 这说的是我 | 具体化痛点（动作、台词、场景），不要空泛 |
| 蓄力 | 10–30s | 忍住、等反转 | 主角隐忍、收集证据、身份铺垫 |
| 反转 | 30–50s | 爽、意外 | 身份揭露、实力打脸、认知推翻 |
| 高潮 | 50–80s | 情绪峰值 | 冲突总爆发、关键台词 |
| 留钩 | 结尾 2s | 想看下一集 | 悬念字幕、新危机降临、开放式提问 |

拆解时记录每个节点的实际时间点和"手法描述"，不记录具体台词。判断标准：情绪不能平，必须有起伏；不能一直高，必须有张弛。

### 第三层：节奏参数

记录可量化的指标：

- 总时长（秒）
- 镜头切换密度（每秒镜头数或平均单镜头时长）
- 反转间隔（两次反转之间隔多少秒）
- 信息密度（单位时间内抛出的新信息点数量）
- 原片引用占比（原剧画面占视频总时长比例，合规值应低于 30%）

这些数字是模板里可直接复用的参数，不涉及内容版权。

### 第四层：选题角度

- **人群**：明确指向谁（都市女性 / 职场新人 / 中年男性 / 小镇青年）
- **痛点**：具体的现实困境（被 PUA、被退婚、买房压力、原生家庭）
- **切口**：从哪个非套路角度进入（地域文化反差、电影质感、社会议题）
- **标题写法**：痛点词前置、数字、反常识、提问式

## 可迁移性判定

拆完后对每个要素打标签：

- **结构（可学）**：钩子类型、情绪节点顺序、节奏参数、痛点分类、叙事手法
- **内容（不可搬）**：具体台词、角色名、剧情专有名词、原片镜头、BGM、完整故事线

输出模板时只使用"结构"标签的要素。

## 常见误区

- 把"某句台词很火"当成结构 → 应归因为台词背后的情绪触发机制
- 只拆开头不拆结尾 → 留钩设计是完播和追更的关键，必须拆
- 忽略节奏参数 → 同一结构换节奏效果完全不同，参数必须记录
- 把题材当结构 → 题材是内容层，可借鉴的是"题材 × 人群 × 痛点"的组合逻辑
